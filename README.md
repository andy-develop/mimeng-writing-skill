# mimeng-writing-skill

> An [Agent Skill](https://agentskills.io) for **Mimeng-style new-media writing** (咪蒙式新媒体写作) — the reproducible writing craft behind the 2015–2018 WeChat golden era: headline formulas, opening hooks, story-driven narrative, aphorism density, emotional pacing, and interaction-driven endings.

**Companion to [`mimeng-perspective-skill`](https://github.com/andy-develop/mimeng-perspective-skill)** (thinking framework / expression DNA). This one is the *hands-on writing workflow*: pick a topic, get a headline set, a hook, a five-part structure, and a pre-publication checklist — in Mimeng's voice.

## ⚠️ Read this first

- This skill reproduces **writing technique only** — including the parts of Mimeng's craft that got her banned across the Chinese internet in 2019 (fabricated "my friend" cases, manufactured anxiety, tragedy exploitation).
- The skill ships hard red lines up front (no fabricated cases presented as real, no fake news/data, no stoking social antagonism, no consuming tragedy, no clickbait that lies). **Technique can be pointed in any direction; keep it pointed at honest, responsible content.**
- No original articles of Mimeng are included in this repository.

## What it is

A writing-craft Agent Skill. Once installed, activate it with one sentence (Chinese triggers work best):

```
用咪蒙体写一篇关于 XX 的文章
帮我写个 10w+ 标题，主题是 XX
帮我把这篇稿子改成爆款风格
```

It then drafts in the Mimeng register — short sentences, parallelism, punchlines, concrete numbers — and always returns: headline set (3 options) → hook → five-part body → marked aphorisms → ending, plus a compliance self-check.

## Install

Copy the `SKILL.md` into your agent runtime's skill directory (e.g. Claude Code `.claude/skills/mimeng-writing/SKILL.md`, or your runtime's equivalent), or clone this repo and point the runtime at it.
